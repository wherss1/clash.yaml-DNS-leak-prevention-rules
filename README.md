这是一份专为极致性能与AI服务深度调优的 Clash / Mihomo (Clash.Meta) 终极配置文件。告别高负载与 DNS 污染，国内直连零损耗，外网访问稳如老狗。
🚀 核心亮点
TUN 模式极低负载（核心）
独创国内 IP 绕过 TUN 内核直连（route-exclude），CPU 占用骤降。国内游戏、视频、局域网访问丝滑无感，告别传统 TUN 模式的高耗能。
AI 服务专属通道
内置 OpenAI / Claude / Gemini 专属策略组，自动剔除港/新等受限节点，强制优选美/日/韩节点，彻底告别“该地区不可用”。
QUIC 拦截与网页秒开
智能拦截 443 端口 UDP 流量（QUIC），强制回退 TCP，完美解决 YouTube 视频转圈、网页白屏及频繁断开的痛点。
全面 DoH 防劫持体系
彻底废弃明文 DNS，采用加密解析。精准匹配国内外 CDN，杜绝运营商劫持、DNS 污染与跨域报错。
深度广告与流氓拦截
内置针对国内生态的精准 REJECT 规则，屏蔽常见追踪器、流氓软件（如 360/迅雷等）及路由器管理域名误触。
🛠️ 贴心细节
多机场聚合：支持最多 7 个订阅源，港/台/日/新/美/韩自动测速选优。
NTP 时间同步：底层保障系统时间，杜绝因时间误差导致的 TLS 握手/证书验证失败。
TLS 指纹伪装：默认 Chrome 指纹，有效防止节点被严格防火墙精准阻断。
Fake-IP 优化：精准过滤微软、苹果、Steam 的国内 CDN，确保系统更新与游戏下载满速。
💡 适用场景
完美适配 OpenWrt/iStoreOS 软路由、Windows/Mac 全局 TUN 模式 及 Android 客户端。规则逻辑严密，小白可直接导入使用，进阶玩家可随心微调。
